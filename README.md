# 幸运之子——摇号机（RandomDrawer）

一个单文件 C# / WinForms 抽号小工具：在指定数字区间里抽号，支持**垫底名单**（最后才抽）、**权重**、重复控制和摇号动效。
配置放在 exe 同目录的 `settings.ini`，绿色便携。

- 产物：`dist\幸运之子——摇号机.exe`（≈24 KB，x86 / .NET Framework 4.x，Windows 自带运行时，免安装）
- 界面：中文，窗口标题「随机抽号器」
- 无需联网、不请求管理员权限

## 编译与测试

双击 `build.cmd` 编译，双击 `test.cmd` 跑测试（各 23 项）。命令行：

```powershell
.\build.ps1     # 编译到 dist\
.\test.ps1      # 编译并运行 tests\PickerTests.cs
```

两者都用 **Windows 自带的 `csc.exe`**（`%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`），
**不需要安装 .NET SDK / Visual Studio**；脚本位置无关，整个文件夹可以随便挪动。

## 使用

主界面：填「开始 / 结束 / 每次抽取」，按需勾选「不允许重复」「摇号特效」，点 **随机抽号**。

- 结果按 `6/18/` 的形式追加在下方结果框，左侧显示 `抽号结果  已抽取:N个`
- **重新开始** 清空本轮已抽记录
- 关闭程序时会把界面上的当前值写回 `settings.ini`，所以「结束填 52 → 关掉 → 再打开」仍是 52

### 隐藏设置面板（输入 `1016`）

在 **「开始」框里输入 `1016`**，再点 **随机抽号** → 打开设置面板（沿用原程序的隐藏入口）。
打开后「开始」框会恢复成设置里的默认值。

| 项目 | 说明 |
| --- | --- |
| 垫底号码 | 这些号码**最后才会被抽中**：只要还有别的号码可选就轮不到它们，普通号码抽完才会轮到（不是"永远不中"） |
| 权重号码 | `号码=倍数`，倍数越大越容易抽中；`6=5` 表示 6 号权重是 5 倍 |
| 中签概率预览 | 按单次抽取算出每个号码的实际概率，用来检查权重是否合理（例：44 个号里 6 号权重 5 → 6 号 10.87%、其余 2.17%） |
| 界面默认值 | 开始 / 结束 / 每次抽取 / 两个勾选项：下次打开程序时的初始值 |
| 恢复默认 | 清空垫底与权重，界面默认值回到 1 / 44 / 1 / 勾选两项（有二次确认） |

号码与权重的写法：

- 号码分隔符：`,` `，` 空格 `Tab` 换行 `、` `/` `;` 全角空格
- 权重行分隔符：`=` `:` 空格，一行一个，也可用逗号隔开多组
- 倍数必须是正数，非法条目会被忽略

## 配置文件 `settings.ini`

与 exe 放在同一目录（UTF-8，可手动编辑，改完重启程序生效）：

```ini
Start=1
End=52
Count=1
NoRepeat=1
Effect=1
Bottom=18,19
Weights=6=5
```

该目录不可写时（例如放进 `Program Files`）自动改用 `%APPDATA%\RandomDrawer\settings.ini`。

> 旧版本把配置写在注册表 `HKCU\Software\随机抽号器`。首次运行若检测到旧键且没有 `settings.ini`，会自动迁移过来（旧键保留不动）。

## 来龙去脉

桌面上原本只有一个 13,824 字节的 `幸运之子——摇号机.exe`，源码已丢失（疑似随 E 盘事故一并丢失）。
本工程用 dnfile + dncil 反汇编该 exe 的 IL，**逐条还原**成可编译的 C# 源码，验证后再改造。
原始二进制已留档在 `reference/幸运之子——摇号机.original.exe`（SHA256 `881DB614…D64B69C`），
以后要重新比对还原保真度时还用得上。

还原保真度（与原 exe 对比）：

- 控件树（类名 / 文本 / 坐标 / 尺寸）**15 项全部一致**
- 主界面截图**像素级完全一致**（ImageMagick `AE=0`、`RMSE=0`）
- 装配名、CLR 版本 v4.0.30319、32 位 PE、图标与版本资源一致

原程序的行为特点（保留）：抽号用轮盘赌权重、结果追加显示、`1016` 隐藏入口、数据存注册表。
本次改造（见 `CHANGELOG.md`）：垫底名单替代"永远不中"、界面参数记忆、设置面板扩展、算法独立成类并加测试。
