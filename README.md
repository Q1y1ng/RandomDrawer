# 幸运之子——摇号机（RandomDrawer）

一个单文件 C# / WinForms 抽号小工具：在指定数字区间里抽号，支持权重、屏蔽名单、重复控制和摇号动效。

- 产物：`dist\幸运之子——摇号机.exe`（x86 / .NET Framework 4.x，Windows 自带运行时，免安装）
- 界面：中文，窗口标题「随机抽号器」
- 无需联网、不请求管理员权限

## 编译

双击 `build.cmd`，或在 PowerShell 里：

```powershell
.\build.ps1
```

用 **Windows 自带的 `csc.exe`**（`%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`）编译，
**不需要安装 .NET SDK / Visual Studio**。脚本位置无关，整个文件夹可以随便挪动/拷贝。

### 原程序行为

1. 主界面：开始 / 结束 / 每次抽取 / 不允许重复 / 摇号特效 / 随机抽号 / 重新开始，下方是结果框。
2. 输入校验：三个框都要是合法整数、`开始 ≤ 结束`、`每次抽取 ≥ 1`，否则弹「请输入正确的数字！」。
3. 候选池 = 区间内号码 **去掉屏蔽名单**；勾选「不允许重复」时再剔除本轮已抽过的号，空了弹「都选完啦！」。
4. 按权重抽号（缺省权重 1.0），抽出即移出池子。
5. 勾选「摇号特效」时用 60 ms 定时器滚动大字约 22 次（≈1.3 秒），再落定真正抽出的结果。
6. 结果追加到结果框，形如 `6/18/`，标题显示 `抽号结果  已抽取:N个`。

### 隐藏设置面板

在 **「开始」框里输入 `1016`**，再点 **随机抽号**，即可打开隐藏的「设置」面板（输入框里会显示当前屏蔽名单与权重）。

| 项目 | 说明 |
| --- | --- |
| 屏蔽号码 | 这些号码永远不会被抽中 |
| 权重号码 | `号码=倍数` 形式，如 `6=5` 表示 6 号的权重是 5 倍 |

号码分隔符：`,` `，` 空格 `Tab` 换行 `、` `/` `;`；权重行分隔符：`=` `:` 空格；倍数必须是正数。

配置存在注册表 `HKCU\Software\随机抽号器`（本版与原程序一致，下一版改为 `settings.ini`）。
